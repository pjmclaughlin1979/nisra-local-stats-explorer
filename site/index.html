Local Statistics Explorer

An unofficial recreation of the NISRA explorer, built twice on one shared core.

React version

React 19 with the ArcGIS Maps SDK for JavaScript 5.x map component.

Open the React app →

Svelte version

Svelte 5 (runes) with the same ArcGIS 5.x map component and shared core.

Open the Svelte app →

Both apps read statistics live from the NISRA Data Portal, council boundaries from the ONS Local Authority Districts service and District Electoral Area boundaries from DAERA. All data is available under the Open Government Licence.

The official service is the NISRA Local Statistics Explorer.
